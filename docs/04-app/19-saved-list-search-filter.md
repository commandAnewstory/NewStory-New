# 19. 보관함 탭: 홈 스타일 목록 + 검색·카테고리·변환종류 필터

> 선행: 백엔드 20번 머지 (`category` 필드)

## 목표 (2026-10-18 사용자 요청)
보관함/히스토리 목록을 홈처럼 텍스트 리스트로 바꾸고(사진 안 씀), 제목 검색 + 카테고리별 + 변환종류별 필터.

## 결정 (사용자)
- 배치: **보관함 탭 위에 바로** — 보관함/히스토리 세그먼트 아래 검색창 + 카테고리 칩 줄 + 변환종류 칩 줄. 세그먼트 바꿔도 검색어·필터 유지
- 걸러내기는 앱에서 즉시 (목록이 사용자별이라 작음)

## 무엇을 하는가
1. 목록 한 줄 = 카테고리 배지(홈 색) + 기사 제목 + 변환종류 칩(동화체/소설체/카드요약 색 토큰) + 시간(보관함: 저장 시각, 히스토리: 마지막으로 본 시각). 누르면 지금처럼 저장된 결과 화면, 길게 눌러 삭제도 그대로
2. 검색: 기사 제목 부분 일치(대소문자 무시, 앞뒤 공백 무시), 지우기 버튼
3. 카테고리 칩: 전체/정치/경제/사회/문화/IT/스포츠 (홈과 같은 `CategoryChipBar`). 카테고리 없는 기사(직접 변환)는 '전체'에만
4. 변환종류 칩: 전체/동화체/소설체/카드요약
5. 셋 다 AND. 결과 없으면 "조건에 맞는 항목이 없어요" + 필터 초기화 버튼. 원래 비어 있으면 기존 빈 화면 문구 그대로

## 구현 메모
- 보관함·히스토리를 같은 `SavedEntry`로 맞추고 `SavedFilter.apply`(순수 함수)로 거름. 히스토리 시간은 마지막으로 본 시각(`viewedAt`)
- 예전 2단 카드(`bookmark_card.dart`)와 안 쓰던 `result_list_item.dart` 삭제
- 홈 목록도 카테고리 없는 기사(직접 변환)는 빈 배지 대신 배지 생략 (18번 후속)
- 검색 화면 테스트(14번)의 실시간 타이머 대기를 60ms → 250ms로 — 전체 테스트를 병렬로 돌릴 때 가끔 실패하던 것

## 영향 범위
- `app/lib/features/bookmarks/bookmarks_screen.dart`, `bookmarks_provider.dart`(모델에 `category`, 필터 상태), `widgets/` (홈 스타일 리스트 항목으로 교체)
- `app/test/**`
