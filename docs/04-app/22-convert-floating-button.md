# 앱 22. 변환 상태 플로팅 버튼

## 목표
변환 중에 상세 화면을 나가면 어떤 기사가 변환 중인지, 끝났는지 알 수 없음 → 어느 화면에서든 보이는 플로팅 버튼으로 알려준다.

## 동작 (사용자 확인 2026-10-19)
- 변환이 하나라도 걸려 있을 때만 생김 (평소엔 없음), 오른쪽 아래
- 생성 중: 연노랑 원 + 테두리 로딩 링이 돎
- 전부 끝나면: 진한 노랑 + 체크, 끝나는 순간 한 번 흔들림. 실패가 있으면 빨간 테두리
- 2개 이상이면 개수 배지
- 누르면 목록 시트 (1개여도 시트): 기사 제목 · 스타일 · 상태(만드는 중/완료/실패). 누르면 그 기사의 그 스타일 탭으로 이동
- 끝난 작업은 상세에서 결과(또는 실패 안내)를 보면 목록에서 빠짐, 다 빠지면 버튼도 사라짐
- 그 기사 상세 화면에선 그 기사 작업은 빼고 보여줌 (화면에 이미 로딩/결과가 보이니까)
- 로그아웃 상태·로그인 화면에선 안 보임, 로그아웃하면 목록 비움 (늦게 끝난 요청도 다시 안 들어옴)

## 구현
- `core/convert/convert_jobs.dart`: 전역 작업 목록 `convertJobsProvider` (start / finish / seen / clear), 로그아웃 시 clear
- `ArticleDetailNotifier`가 변환 시작·성공·실패를 보고
- `ArticleDetailScreen`: 결과/실패를 화면에 띄우면 `seen`
- `core/convert/convert_jobs_fab.dart`: `withConvertJobsFab` — `MaterialApp.router` builder에서 앱 전체 위에 얹음. 현재 경로는 `router.state`로 판단(push로 쌓인 화면 포함)
- 버전 1.0.2+3
