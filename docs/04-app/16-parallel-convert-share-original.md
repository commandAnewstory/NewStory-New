# 16. 스타일 동시 생성 + 공유 전체 텍스트 + 원문 보기 버튼

> 선행: 앱 15번 머지 (같은 화면 파일을 고쳐서 15번 위에서 작업)

## 배경 (2026-10-17 실기기 확인 중 사용자 요청)
1. 동화체 생성 중에 다른 스타일 버튼을 누르면 생성이 "중단"된 것처럼 보임. 원인: 생성 중 표시가 기사 하나에 하나(`isConverting`)라서, 먼저 끝난 요청이 표시를 꺼버리면 아직 생성 중인 탭이 빈 화면이 됨. 서버 요청 자체는 끝까지 감
2. 공유하면 동화체·소설체 변환문이 200자에서 `…`으로 잘림 → 전체를 보내기
3. 기사 상세에 원문(크롤링한 원본 기사 링크)으로 가는 버튼이 없음 (15번에서 실패 화면에만 추가했음)

## 결정 (사용자)
- 1번: **동시에 진행** (생성 중 잠금 대신). 스타일마다 따로 생성되고, 다른 탭을 보거나 화면을 나갔다 와도 계속 진행
- 2번: 변환문 전체 + 원문 링크 (2026-10-12 결정의 "앞 200자"를 바꿈)
- 3번: 기사 상세 하단에 "원문 보기" 버튼 → 외부 브라우저로 원본 링크

## 무엇을 하는가
1. `ArticleDetailState`: `isConverting`/`convertError` 단일 값 → 스타일별 `converting`(Set), `convertErrors`(Map). 화면은 지금 보고 있는 스타일 기준으로만 로딩/에러 표시
   - 생성 중인 스타일 탭을 다시 누르면 난이도 다시 묻지 않고 그 탭으로 이동만 (중복 요청 없음)
   - 스타일 칩 옆에 생성 중 점 표시
   - 응답이 늦게 와도 그 시점의 최신 상태에 합쳐서 다른 스타일 결과를 덮지 않음
2. `buildShareText`: 동화체·소설체도 변환문 전체 (말줄임 제거). 기사 상세·직접 변환·저장된 결과 화면 공통
3. 기사 상세 하단 바: 보관함 저장 / **원문 보기** / 공유. 링크를 못 열면 스낵바
