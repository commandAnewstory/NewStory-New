# 14. 검색 화면 + 알림 아이콘 제거

> 선행: 백엔드 16번 머지 (`GET /api/news?keyword=`)

## 목표
홈 상단의 돋보기·종 아이콘이 지금은 그림만 있고 눌러도 아무 일 없음. (2026-10-16 사용자 결정)
- **알림**: 기능 안 만듦 → 종 아이콘 제거
- **검색**: 별도 검색 화면, 입력하면서 자동 검색, 카테고리 필터

## 무엇을 하는가
1. 홈 헤더에서 종 아이콘(`BellIconPainter`) 제거 — 코드에서도 삭제. 돋보기는 남기고 누르면 검색 화면으로 이동
2. 새 라우트 `/home/search` — 검색 화면
   - 상단: 뒤로가기 + 검색창(자동 포커스, 지우기 버튼)
   - 그 아래: 카테고리 칩 (홈과 같은 `CategoryChipBar` — 전체/정치/경제/사회/문화/IT/스포츠)
   - 결과: 홈과 같은 `ArticleListTile` 목록, 무한 스크롤(20개씩), 누르면 기사 상세
   - 타이핑 멈추고 0.3초 뒤 자동 검색. 칩 누르면 바로 다시 검색
   - 늦게 도착한 이전 검색 응답이 최신 결과를 덮어쓰지 않게 처리
3. 상태별 화면
   - 검색어 비어 있음: "기사 제목으로 검색해보세요" (요청 안 보냄)
   - 결과 없음: "'검색어'에 맞는 기사가 없어요"
   - 실패: "다시 시도" 버튼
4. 검색창 50자 제한 (백엔드와 동일)

## 구현 메모
- `SearchNotifier`: 요청마다 순번을 올리고 응답 때 최신 순번이 아니면 버림 (느린 이전 응답이 새 결과를 덮지 않게). 검색어를 지우면 대기 중인 요청도 무효화
- 검색어 없이 카테고리만 바꾸면 요청 안 함 (카테고리별 목록은 홈에서 봄)
- 화면 떠나면 상태 초기화 (autoDispose) — 다시 열면 빈 검색창
- `FakeApi`가 Future 응답도 받도록 확장 (응답 순서 테스트용)

## 영향 범위
- `app/lib/features/home/home_screen.dart` (아이콘 정리 + 돋보기 탭)
- `app/lib/features/search/` (신규: `search_provider.dart`, `search_screen.dart`)
- `app/lib/features/home/article_repository.dart` (`keyword` 파라미터 추가)
- `app/lib/core/router/app_router.dart` (라우트 추가, `BellIconPainter` 삭제)
- `app/test/**`
