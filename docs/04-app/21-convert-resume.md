# 앱 21. 변환 중 화면 유지 · 다시 들어와도 이어보기

## 문제 (실사용 피드백)
- 홈 위젯으로 들어오면 변환이 시작되기 전(기사·난이도 불러오는 동안) 화면이 비어 있어 변환 중인지 모름
- 그 사이 다른 스타일 눌렀다가 다시 누르면 난이도 선택 화면이 뜸
- 변환 중 뒤로 갔다가 다시 들어오면 원문 탭으로 열려서 변환이 끊긴 것처럼 보임 (실제 요청은 provider에서 계속 진행 중)
- 실패한 스타일을 다시 누르면 난이도 선택으로 돌아감

## 변경
- `openWithStyle`: 기다리기 전에 먼저 "생성 중"으로 표시 → 바로 로딩 화면, 중복 요청 없음. 기사 로드 실패 시 실패 안내
- 상태에 `lastTab` 추가, 화면 탭 바뀔 때마다 `setTab`으로 기록 → 다시 들어오면 보던 스타일 탭(생성 중이면 로딩, 끝났으면 결과)으로 열림. 원문 보다 나갔으면 원문
- 스타일 탭 이동 판단을 `hasActivity`(결과·생성 중·실패)로 — 실패한 스타일은 실패 안내 + 다시 시도
- 화면은 전부 지금 탭 기준으로 결과/로딩/실패 표시
- 로딩 화면: "카드요약 만드는 중이에요 / 보통 20~40초, 뒤로 가거나 다른 탭을 봐도 계속 만들어요"
- 다시 시도: 기사 자체를 못 불러온 경우 기사부터 다시, 난이도는 사용자 기본값
