# NewStory 기획 문서

이 폴더는 NewStory 앱 리빌드 프로젝트의 기획 문서를 관리한다. 문서는 항상 **마스터 기획서 → 하위 기획서** 순서로 참고한다: 실제 개발(백엔드/앱)에 들어가기 전, 해당 작업 단위의 하위 기획서를 마스터 기획서 기준으로 작성하고 확인받은 뒤 진행한다.

## 폴더 구조

```
00-master/       마스터 기획서. 프로젝트 전체의 기준 문서. 다른 모든 문서는 이 문서를 기준으로 작성된다.
01-decisions/    굵직한 의사결정 기록 (디자인 방향 선택, 뉴스 수집 방식 전환 등). 날짜-주제 형식 파일명.
02-design/       디자인 토큰, 화면별 설명. 실제 비주얼 목업은 Claude 아티팩트 캔버스에 별도 보관.
03-backend/      백엔드 하위 기획서. 마스터 기획서 8장 "개발 순서"의 번호를 그대로 파일명 접두어로 사용.
04-app/          Flutter 앱 하위 기획서. 백엔드 작업 완료 후 착수.
05-db/           DB 스키마 변경사항 상세 (마이그레이션 단위).
```

## 문서 작성 규칙
- 하위 기획서 파일명은 `NN-주제.md` 형식으로 마스터 기획서의 개발 순서를 따른다.
- 마스터 기획서 자체를 바꾸는 결정(기능 추가/제외, 디자인 변경, API 구조 변경)이 나오면 `00-master/master-plan.md`를 갱신하고, 필요하면 `01-decisions/`에 왜 바꿨는지 기록을 남긴다.
- 이 문서들은 Claude 프로젝트(claude.ai)의 `claude/newstory-master-plan.md`, `claude/newstory-app-rebuild-brief.md`와 내용이 같은 계열이다. 둘 중 하나만 갱신하고 잊어버리지 않도록, 마스터 기획서 갱신 시 양쪽 다 반영한다.
