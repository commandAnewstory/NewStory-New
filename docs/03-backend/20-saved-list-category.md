# 20. 보관함·히스토리 응답에 기사 카테고리 추가

> 짝: 앱 19번 (보관함 탭 홈 스타일 목록 + 검색·카테고리·변환종류 필터)

## 목표 (2026-10-18 사용자 요청)
보관함·히스토리에서 제목 검색 + 카테고리별 + 변환종류별 필터. 목록은 사용자별이라 작아서 **걸러내기는 앱에서** 하고(타이핑 즉시 반영), 서버는 앱이 카테고리를 알 수 있게 응답에 필드만 추가한다.

## 무엇을 하는가
- `GET /api/history`, `GET /api/bookmarks` 각 항목에 `category` 추가 (기사 카테고리, 직접 변환한 기사는 null)
- 응답 필드 **추가만** — 기존 앱 그대로 동작

## 영향 범위
- `HistoryResponse`, `BookmarkResponse`, `BookmarkHistoryFlowTest`, 마스터 기획서(보관함 화면·엔드포인트 표)

## 완료 기준
- RSS 기사 → 카테고리 값, 직접 변환 기사 → null (보관함·히스토리 둘 다), 기존 테스트 통과
