# 앱 Bundle ID / 프로젝트 위치 확정

## 무엇을 결정했는가
- Flutter 앱 Bundle ID(Android 패키지명 / iOS 번들 ID) 공통값: `com.newstory.app`
- 구 프로젝트 폴더(`~/Desktop/프로젝트/newspace/newstory`)는 앞으로 참고용으로만 두고 더 이상 수정하지 않는다.
- 신규 프로젝트(백엔드 포함 전체)는 `~/Desktop/NewStory` 폴더 안에 처음부터 새로 만든다. 기존 백엔드 코드를 그대로 옮기는 게 아니라, 마스터 기획서 기준으로 전부 새로 작성한다.
- 배포도 구 프로젝트 기준이 아니라 새 `NewStory` 폴더 기준으로 다시 세팅한다 (서버/인프라/CI 등 구 폴더에 있던 배포 설정은 참고만 하고 그대로 재사용하지 않음).

## 왜 그렇게 결정했는가
- Bundle ID는 이미 Google Cloud OAuth 클라이언트(Android/iOS) 등록 시 `com.newstory.app`로 발급받아서 그대로 확정.
- 구 폴더는 스펙-실제 코드 간 괴리, 미해결 버그(verificationPassed 로직, `/api/test/**` 노출) 등이 있어 그대로 이어받기보다 마스터 기획서 기준으로 재작성하는 쪽으로 이미 방향을 잡았음 — 이번 확답으로 "부분 재사용"이 아니라 "전체 새로 작성"임을 명확히 함.

## 마스터 기획서 반영
- `docs/00-master/master-plan.md`의 아키텍처/개발 순서 섹션에 "신규 프로젝트는 NewStory 폴더에 전부 새로 작성, 구 폴더는 참고용" 명시.
- 하위 기획서 작성 시 구 코드는 "참고 자료"로만 인용하고, 실제 구현은 새 폴더 기준으로 진행한다.
