# 변환 결과 재사용 + 히스토리 숨김

## 무엇을 결정했는가
1. 같은 사용자가 같은 기사·스타일·레벨을 다시 열면 `converted_results`에 새 행을 만들지 않고 기존 행을 재사용한다 (A안). 히스토리는 "마지막으로 본 시간" 순.
2. 보관함에 저장된 항목을 히스토리에서 지우면 행을 지우지 않고 **히스토리에서만 숨긴다**. 보관함엔 그대로 남고, 같은 기사를 다시 보면 히스토리에 다시 나타난다. 보관함에 없는 항목은 지금처럼 실제 삭제.

## 왜 그렇게 결정했는가
- 기존엔 다시 열 때마다 새 행이 생겨 히스토리에 같은 항목이 중복으로 쌓였고, 보관함 저장 여부가 매번 새 `resultId` 기준이라 "저장됨" 상태를 유지할 수 없었음 (앱의 보관함 저장 토글을 만들려면 필요)
- 보관함 항목을 히스토리에서 지우면 FK 제약 때문에 서버가 500을 내고 있었음 (테스트로 재현). 보관함과 히스토리가 같은 행을 가리키는 구조라, 히스토리 삭제가 보관함을 건드리지 않게 하는 쪽을 선택
