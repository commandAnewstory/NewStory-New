# 2026-10-16 검색 추가, 알림 제외

## 배경
홈 상단에 돋보기·종 아이콘이 그림만 있고 동작하는 기능이 없었음 (마스터 기획서 백로그에도 없음).

## 결정 (사용자)
- **알림**: 만들지 않는다. 홈의 종 아이콘도 제거
- **검색**: 기사 **제목** 부분 일치(`LIKE %검색어%`) + 카테고리 필터
  - API는 새로 만들지 않고 기존 `GET /api/news`에 `keyword` 파라미터 추가
  - 앱은 별도 검색 화면(`/home/search`), 입력하면서 0.3초 뒤 자동 검색

## 참고
- 인덱스 없는 LIKE라 풀스캔이지만 기사는 한 달치만 보관(매일 03시 정리)이라 지금 규모에선 충분. 커지면 PostgreSQL `pg_trgm` 인덱스 검토
